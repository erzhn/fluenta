# AUDIT — Fluenta

Полный аудит сайта. Документ живой, обновляется по ходу фаз.

- **Проект:** Fluenta — edtech-приложение для изучения английского с AI-репетитором Zhan.
- **Цель продукта:** вовлечь в ежедневную практику (разговор, грамматика, лексика, произношение), удержать через геймификацию (XP/стрик/уровни).
- **Стек:** Next.js 16 (App Router, RSC, Turbopack), React 19, TypeScript, Tailwind CSS v4, framer-motion, lucide-react, Supabase (auth + БД), Gemini/Groq (AI), next-themes. PWA (sw.js, manifest, offline).
- **Запуск:** `npm run dev` (порт 3000). Прод: Vercel.
- **Критично для владельца:** «не скучный, современный дизайн с анимациями» (из предыдущих задач) + корректная геймификация.

## Ограничения этого аудита (важно — Правило 5)
- **Приложение за авторизацией** (Supabase email-OTP). Залогиниться в этой сессии нельзя → рантайм-проверки экранов дашборда (Фазы 2–5) **не выполнены**.
- **Скриншоты недоступны** — панель браузера в сессии не рендерит кадры → Фаза 3 (визуальный адаптив) и скрины **не выполнены**.
- **Lighthouse/Playwright не запускались** — нужен живой авторизованный инстанс. Порт 3000 занят другим процессом.
- Что проверено статически (Фазы 0, 1, частично 6, 7) — помечено; остальное помечено **НЕ ПРОВЕРЕНО** с причиной.

### Ограничение среды (важно)

Отличить «Groq недоступен из песочницы» от «невалидный ключ» без твоего реального окружения нельзя. На твоём dev/проде с валидным ключом и открытой сетью генерация должна работать; проверь Lighthouse/реальные AI-потоки у себя.
